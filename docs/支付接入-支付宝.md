# 支付宝收款接入说明（Lexiverse Pro）

本文档覆盖「电脑网站支付 alipay.trade.page.pay」的完整接入：环境变量、开放平台配置、密钥生成、回调地址、本地/沙箱/线上测试清单与订单表结构。

实现代码无第三方支付 SDK，RSA2(SHA256withRSA) 签名/验签用 `node:crypto` 完成，位于 `src/lib/pay/alipay.ts`。

## 1. 环境变量

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `ALIPAY_APP_ID` | 是 | 开放平台应用的 APPID（沙箱与正式不同） |
| `ALIPAY_PRIVATE_KEY` | 是 | 应用私钥（RSA2）。支持：PKCS8 裸 base64、带 `BEGIN PRIVATE KEY` 的 PEM、带 `BEGIN RSA PRIVATE KEY` 的 PKCS1 PEM；`\n` 字面转义会自动还原 |
| `ALIPAY_PUBLIC_KEY` | 是 | **支付宝公钥**（不是应用公钥），用于验签异步通知 |
| `ALIPAY_GATEWAY` | 否 | 默认 `https://openapi.alipay.com/gateway.do`；沙箱用 `https://openapi-sandbox.dl.alipaydev.com/gateway.do` |
| `ALIPAY_NOTIFY_URL` | 建议 | 异步通知地址：`{NEXT_PUBLIC_SITE_URL}/api/pay/notify`。必须公网可达，否则只能靠查单兜底 |
| `ALIPAY_RETURN_URL` | 建议 | 同步回跳地址：`{NEXT_PUBLIC_SITE_URL}/pay/return` |
| `ALIPAY_SELLER_ID` | 否 | 收款方支付宝 PID（2088 开头）。设置后 notify 会额外校验 `seller_id` |
| `AI_CHAT_FREE_DAILY_LIMIT` | 否 | 免费用户每日 AI 对话额度，默认 20 |
| `AMBIENT_FREE_DAILY_LIMIT` | 否 | 免费用户每日 AI 文章生成额度，默认 3 |

三要素（APP_ID + PRIVATE_KEY + PUBLIC_KEY）任一缺失时 `isAlipayConfigured()` 为 false：`POST /api/pay/orders` 返回 `503 {code:'PAY_NOT_CONFIGURED'}`，pricing 页按钮禁用。

## 2. 开放平台配置步骤

1. 登录 [支付宝开放平台](https://open.alipay.com/) → 控制台 → 创建「网页&移动应用」。
2. 个人开发者：先做沙箱联调（控制台 → 沙箱），沙箱自带测试 APPID、测试买家/卖家账号。
3. 应用添加「电脑网站支付」能力并签约（正式环境需营业执照等资质；个人可先全程沙箱演示）。
4. 接口加签方式选择「公钥」模式（RSA2）：
   - 用「支付宝开放平台开发助手」生成密钥对，得到**应用私钥**与**应用公钥**；
   - 上传应用公钥后，页面给出**支付宝公钥**（验签用它，别拿错）。

## 3. 密钥格式

推荐 PKCS8（开发助手默认输出）。私钥应形如：

```
-----BEGIN PRIVATE KEY-----
MIIEvwIBADANBgkqhkiG9w0BAQEFAASC...
-----END PRIVATE KEY-----
```

写进 `.env` 时可以整段多行粘贴，也可以把换行写成 `\n` 字面量（`ALIPAY_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIE...\n-----END PRIVATE KEY-----"`），`toPem()` 会统一归一化。PKCS1（`BEGIN RSA PRIVATE KEY`）同样兼容：裸 base64 会先按 PKCS8 试签，失败后自动回退 PKCS1 头。

## 4. 回调地址

- **notify_url（服务端→服务端）**：`https://<域名>/api/pay/notify`，公网可达、POST、form-urlencoded。本地联调用 ngrok/cpolar 等隧道暴露：`ngrok http 3000`，把临时域名配进 `ALIPAY_NOTIFY_URL`。注意沙箱支付页不会回调 localhost。
- **return_url（浏览器同步回跳）**：`https://<域名>/pay/return`，前端页轮询 `GET /api/pay/orders/{outTradeNo}`（≤15s）确认支付状态。

## 5. 链路与时序

```
/pricing ──POST /api/pay/orders──> 建 PaymentOrder(pending) + 返回 payUrl
        ──跳转支付宝收银台──> 用户付款
        ──notify_url POST──> verifyNotify → fulfillPaidOrder → order=paid + user.plan=pro(+days)
        ──return_url──> /pay/return 轮询 GET /api/pay/orders/{outTradeNo}
                          └─ pending 时主动 alipay.trade.query 兜底（同样走 fulfillPaidOrder）
```

- 幂等：`fulfillPaidOrder` 先 `updateMany({status:'pending'})` 抢占，重复 notify/查单并发只会成功一次。
- 续期：`planExpiresAt = max(now, 现有 planExpiresAt) + product.days`。
- 金额校验：notify 的 `total_amount` 与订单 `amount` 数值比较，不等回 `failure` 不发放权益。
- `seller_id` / `app_id` 在验签后复核。

## 6. 测试清单

### 本地（无真实支付）
- `DEMO_MODE=true` 下演示账号为永久 Pro，可用于 UI 走查。
- 未配 ALIPAY_*：`POST /api/pay/orders` → 503 `PAY_NOT_CONFIGURED`；未登录 → 401。

### 沙箱
1. `ALIPAY_GATEWAY=https://openapi-sandbox.dl.alipaydev.com/gateway.do`，换沙箱 APPID/密钥，沙箱版支付宝 App 扫码付款。
2. 隧道暴露 `/api/pay/notify`，观察 `PaymentOrder.status` → `paid`、`alipayTradeNo`、`rawNotify` 落库，`User.plan='pro'` 且 `planExpiresAt` 正确。
3. 重复触发同一通知 → 依然 success 且不重复加天数（幂等）。
4. 断开隧道付款 → `/pay/return` 轮询触发 `queryOrder` 兜底开通。

### 正式
1. 签约「电脑网站支付」，切回正式 `ALIPAY_GATEWAY`（或删掉该 env 用默认值）与正式 APPID/密钥。
2. notify_url 换正式域名；HTTPS 必需。
3. 小额真实付款验证 + 一笔退款流程人工确认（本实现不处理退款回调，退款后需人工把 `User.plan` 降回 `free`）。

## 7. 订单表（`LPT_english."PaymentOrder"`）

| 字段 | 说明 |
| --- | --- |
| `id` | cuid 主键 |
| `outTradeNo` | 商户订单号（`WL{ts}{rand}`），唯一，传给支付宝 `out_trade_no` |
| `userId` | 下单用户（FK → User，级联删除） |
| `product` | 产品 key：`pro_monthly` / `pro_yearly`（目录见 `src/lib/pay/products.ts`） |
| `subject` | 订单标题，显示在收银台 |
| `amount` | DECIMAL(10,2)，应付金额 |
| `status` | `pending` / `paid` / `closed` |
| `alipayTradeNo` | 支付宝交易号（支付成功后回填） |
| `paidAt` | 支付完成时间 |
| `rawNotify` | 原始 notify 参数 JSONB，便于对账排障 |

索引：`outTradeNo` 唯一、`(userId,status)`、`(createdAt)`。另有 `UsageLog` 表（userId, kind, createdAt）记录免费额度用量；`User.plan`/`User.planExpiresAt` 承载会员状态。

## 8. API 速查

| 接口 | 行为 |
| --- | --- |
| `POST /api/pay/orders` | 登录 → 建单 → `{payUrl,outTradeNo}`；未配置 503；未知产品 400；未登录 401 |
| `POST /api/pay/notify` | 支付宝回调。验签失败/订单不存在/金额不符 → `failure`；支付成功 → 开通权益回 `success` |
| `GET /api/pay/orders/{outTradeNo}` | 本人订单状态 `{status,paidAt}`；pending 时查单兜底 |
| `GET /api/auth/me` | `{user{...,plan,planExpiresAt,isPro}, usage, payConfigured}` |
